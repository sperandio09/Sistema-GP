__Sistema GP de Avaliação__ - _SENAI|Sinop_

![Tela de Apresentação](./Frontend/resources/Tela de fundo README - Sistema-GP.png)

_Sistema de avaliação e divulgação de resultados do evento Grand Prix SENAI, da SAGA SENAI de Inovação, desenvolvido pela Embaixadora Júnior da Inovação, Luma Sperandio._

Permite aos mentores e alunos o cadastro de suas escuderias, e aos avaliadores a avaliação das equipes de acordo com os critérios predefinidos. 

Ferramentas:
+ Banco de dados - MySQL
+ Backend - Python + FastAPI
+ Frontend - HTML + CSS e Javascript
