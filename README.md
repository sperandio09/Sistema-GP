# **Sistema de Avaliação Grand Prix de Inovação SENAI - Sinop**

## Sistema de avaliação do evento Grand Prix, da Saga SENAI de Inovação, com o objetivo de automatizar a *avaliação das escuderias e a divulgação dos resultados.*

![Tela de fundo](assets/Tela%20de%20fundo%20README%20-%20Sistema%20GP.png)

### Alunos e mentores podem consultar sobre as escuderias, e posteriormente o ranking das escuderias na data de divulgação, e os avaliadores podem atribuir notas às equipes de acordo com os critérios de avaliação.
